# Selenium  WebDriver learning

A Java-based automation repository for learning and mastering **Selenium WebDriver** and **TestNG** workflows.

## Tech Stack & Dependencies
* **Language:** Java
* **Framework:** TestNG
* **Automation Tool:** Selenium WebDriver
* **Build Tool:** Maven (`pom.xml`)
* **Utilities:** Apache Commons IO (for screenshot file handling)

## Repository Structure
* `src/` : Test scripts, method overloading verifications, and core Java automation logic.
* `resources/` : Target directory for shared public document assets and media files.
* `docs/` :  Collaboration references, including contributor guidance (`contributing.md`).

## Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Alicade123/Selenium.git
   ```
2. **Build the project:**
   Open the codebase in IntelliJ IDEA (`.idea/`) and import the Maven dependencies via your `pom.xml`.
3. **Execute Tests:**
   Run your test execution suites natively using the integrated TestNG test runner.
